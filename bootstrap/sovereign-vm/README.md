## מאמת-השרשרת הבלתי-תלוי (verify_chain.py)

מימוש-Python טהור (אפס-תלות) של חוק-החתימה מ-`index.ts sealTx`:
`body = JSON.stringify({...t, prev}) · h = sha256(body)[:32]`
שחזור מדויק-בייטים בניתוח-מחרוזת גולמי (מסירת-זנב-`"h"`, הוספת-`"prev"` — בלי-שבירת-פורמט-מספרים).
חוקי-העוגנים שוחזרו מדויק לפי `verifyChain` (index.ts:521): גנזיס="GENESIS" · עולה-ממש ·
איסור-עוגנים-עוקבים · איסור-זנב-עוגן · בסיס-3 בדיוק.

```bash
python3 bootstrap/sovereign-vm/verify_chain.py [נתיב-state]   # יציאה 0=ירוק
```

## כללי-בטיחות

- ה-harness **קריאה-בלבד** על הספר (הוכח: git status נקי אחרי-הרצות).
- אפס-סודות באורח; אפס-רשת-חוץ (MOUNTS_ONLY); ה-PAT לעולם לא עובר ל-guest.
- ה-VM אינו-מחליף את כאת-הלב — הוא שכבת-ביקורת/בידוד; הפעימה נשארת על-המארח-הקנוני.

## מפת-דרך (הצעד-הבא-כשיבוא-לידי-ביטוי-בערך)

1. הרצת טסטי-החוק (9.7M טענות) בתוך-VM — בידוד-חישוב מלא.
2. הפעימה-עצמה בתוך-VM (bun באורח + forward-הספר) — החלטה-מרוכזת, אחרי-שבוע-ייצוב.
3. יוזר-פר-סוכן (`create_user`) לתיאום-9-הסוכנים בתוך-VM-אחד.
